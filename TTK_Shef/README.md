# ТТК Шеф — GitHub APK prototype

Загрузка этого проекта в GitHub позволяет автоматически собрать APK через Actions.

После загрузки:
1. Откройте Actions.
2. Выберите Build TTK Shef APK.
3. Нажмите Run workflow.
4. После окончания откройте завершённый запуск.
5. В Artifacts скачайте TTK-Shef-debug-apk.
6. В архиве находится app-debug.apk.

Это прототип. Реальный ИИ, база ТТК, PDF и редактирование добавим следующим этапом.
